# Sources and originality

PriceSignal is an independent software project. Its scope was informed by general pricing decisions—price response, valuation, elasticity, margin, uncertainty, and evidence quality—but its interface, wording, examples, calculations, statuses, export schema, visual identity, and documentation were created specifically for this repository.

The project does **not** copy or adapt lecture slides, course narratives, cases, assessment material, diagrams, datasets, exercises, or proprietary gate and pricing templates. General topics encountered in education—pricing research, demand estimation, willingness to pay—only define the problem domain, and no teaching material is bundled or required to run the software.

The implemented methods are drawn from public statistical, econometric, experimental, and valuation literature cited in the README and methods documentation. Published methods are not owned by this project; the AGPL license applies to PriceSignal's software and documentation expression.

All bundled examples are deterministic synthetic records for fictional settings. They contain no real respondent, customer, company, product, price study, or empirical result.

AI assistance was used during development. Verification includes code review, analytical fixtures with known behavior, deterministic example checks, safe import/export tests, Streamlit page tests, packaging checks, and visual inspection. This does not replace independent review for consequential pricing decisions.
